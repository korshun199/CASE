# VIDEOSCAN

Отдельное полноэкранное приложение компьютерного зрения CASE. Оно показывает
поток UVC-камеры, выполняет детекцию YOLOv8 ONNX на CPU и возвращает пользователя
в главное меню кнопкой «Главное меню».

Параметры модели и камеры задаются в `config/admin_conf.json`: путь к модели,
размер входа, классы, пороги, стабильный путь `/dev/v4l/by-id/...`, разрешение
захвата, частота кадров, интервалы обработки/переподключения и оформление рамок.

На Orange Pi 5 используется модель `models/fpv_drone_custom_320.onnx` с классом
`quadcopter`. Системный OpenCV Debian 4.6 не поддерживает её граф ONNX. Поэтому
камера Brio 90 на Pi5 может менять номер `/dev/videoN` при переподключении,
поэтому используется постоянная ссылка udev по серийному номеру. Приложение
повторно открывает камеру при временной потере потока. Оно запускается через
`/opt/case/videoscan-venv` с
`opencv-python-headless==4.10.0.84`; NumPy берётся из системных пакетов Debian.

Проверено на Pi5: OpenCV 4.10 загрузил ONNX, `/dev/video0` прочитал кадр 640×480,
инференс модели вернул выход `(1, 5, 2100)`. Это подтверждает технический проход
кадра через модель, но не точность распознавания на FPV-виде. Для проверки
точности нужны тестовые видеозаписи/сцены с известной разметкой.

Веса и записи видеопотоков не добавляются в Git. Для установки на Pi5 служит
`scripts/deploy_videoscan_pi5.sh`; скрипт устанавливает системные зависимости,
создаёт защищённое root-окружение, разворачивает приложение и перезапускает
kiosk-службу.
